# Character select

The roster displays ten unnumbered cards in a single-column overlay over the full-screen forest backdrop. Each occupied card shows the class emblem, character name, level, class name in its class colour and last saved location. All ten fit at 1280×800; smaller screens use a scrollbar, with keyboard selection kept in view. Enter World is a compact gold action, while Delete Character is red. Empty slots open creation; occupied slots select a hero for inspection. Create Character, Delete Character and Enter World remain visible. A full roster disables creation and explains how to free a slot. The layout is checked at 960×540, 1280×800 and 1920×1080.

The independent preview uses the same Player model, equipment builder and idle rig as the game. Existing heroes display their saved equipment; unplayed heroes display their class starter gear. Selecting or rotating a hero does not load that hero into the active world or alter their saved progress. Drag the model or use the rotation buttons; the right gamepad stick also rotates it. The preview renders at up to 30 fps while visible, against a lit forest camp backdrop.

Deleting requires the exact character name. It frees a slot and keeps the character and save recoverable for thirty days under Recently Deleted. Restoration requires an available slot. Names remain reserved during recovery. Expired deleted-character saves are removed when the roster is next loaded. Existing active characters and saves retain their IDs and keys. The current build stores these profiles on this computer.

The isolated character-select test checks the ten-character cap, class and saved equipment, idle animation, mouse rotation, screen bounds, creation/cancellation, typed deletion confirmation, exact save preservation, restoration, expiry and entering a restored character with its saved level and equipment. Native Forward+ captures verify the final screen. Existing Godot resource cleanup warnings on exit remain.
